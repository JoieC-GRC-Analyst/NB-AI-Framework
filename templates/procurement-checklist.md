# AI Procurement Checklist — NB‑RAF v1.1

## Vendor Requirements
- [ ] Model Card provided  
- [ ] System Card provided  
- [ ] Security attestations provided  
- [ ] Bias testing results provided  
- [ ] Canadian data residency confirmed  
- [ ] Exit strategy and data deletion plan provided  

---

## Contract Requirements
- [ ] System purpose defined  
- [ ] Prohibited uses defined  
- [ ] Liability and indemnification clauses included  
- [ ] Incident reporting timelines defined  
- [ ] Human oversight requirements documented  
- [ ] OCAP® compliance if First Nations data involved  

---

## Technical Requirements
- [ ] Threat modelling completed  
- [ ] Logging enabled  
- [ ] Version control documented  
- [ ] Explainability available  
- [ ] Bilingual output validated
